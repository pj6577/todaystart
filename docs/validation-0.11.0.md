# 0.11.0 — 공고 통합검색과 공통 UI

검사일: 2026-11-02. 로그인 계정과 실제 입사지원 요청은 사용하지 않았습니다.

## 변경 범위

- 키워드 직접 검색, 직군·직무·지역 복수 선택, 신입~3년·2~5년 및 최소·최대 연차, 무한 스크롤.
- 로컬 지원 기업 제외, 한영 병기 기업명 비교, 최근 지원순 내역 모달과 기록별 공고 링크.
- shadcn 기반 공통 폼·버튼·대화상자·스위치, CSS 분리와 대시보드 기준 콘텐츠 폭.
- 테마 파일 분리에 맞춘 소개 페이지 빌드와 Pages 변경 감지 경로 수정.

## 통과한 검사

- TypeScript 검사, 전체 단위 검사 45개 파일·564개 테스트.
- 프로덕션 0.11.0 빌드, 통합검색 브라우저 검사 18개.
- 기존 UI 브라우저 검사 17개: 대시보드·캘린더·설정·직접 추가·지원 기록 정렬/100건 페이지·CSV/JSON·메모 보드·초기화·오프라인.
- 소개 페이지 로컬 빌드와 대시보드 다크 팔레트 일치 검사.
- 복수 조건·연차 범위의 공개 HTTP 요청: 사람인 HTTP 200·카드 20개, 잡코리아 HTTP 200·카드 25개. 사이트가 반환한 모든 광고·추천 결과의 조건 일치 여부까지 보장하는 검사는 아닙니다.

합성 브라우저 검사에서는 쿠키 미전송, 검색 결과의 영구 저장소 분리, 취소·이전 응답 무시, 부분 실패·재시도, 다음 페이지의 조건 유지, 키보드·모바일·라이트/다크, 지원 내역 모달의 정렬·스크롤·포커스 복귀를 확인했습니다.

## 남은 범위

- 원티드 직군·지역·경력 조건은 연결 전이며 키워드 검색만 요청합니다. 조건을 무시한 결과를 섞지 않습니다.
- 실제 검색 사이트의 접근 제한·시간 초과·구조 변경에 따라 조회에 실패할 수 있습니다. 공개 HTTP 확인과 실제 확장 프로그램의 사이트 연결 결과는 구분합니다.
- 전체 브라우저 스위트 통과를 주장하지 않습니다. 앞선 전체 검사에서 전체 수집의 시간·상태 판정 실패가 남았고, ‘20행 중 8행 인식’ 시나리오는 UI 변경 전 ZIP에서도 실패했습니다. 이번에 해당 수집 문제를 해결했다고 보고하지 않습니다.
- 기존 지원 관찰 content script 4개와 백그라운드 번들은 이전 릴리즈와 바이트를 대조합니다. 저장 구조와 확장 권한은 유지합니다.

## 설치 파일과 공개 범위

- `release/todaystart-0.11.0.zip`: 프로덕션 확장 파일만 포함합니다. Git에는 ZIP을 넣지 않고 GitHub 릴리즈 자산으로 게시합니다.
- `.sha256` 및 `-validation.json`: ZIP CRC, 빌드 파일 일치, 매니페스트 참조·버전·권한·라이선스·주요 민감 패턴 검사 결과입니다.
- 이전 설치 폴더의 파일을 교체하고 확장 프로그램·관리 화면·채용 사이트 탭을 새로고침합니다. 다른 폴더에 중복 설치하면 저장소가 분리될 수 있습니다.
- 검색 결과는 화면 메모리에만 유지합니다. 로컬 지원 기록을 검색 사이트나 운영 서버로 보내지 않으며, Chrome 웹스토어 게시 작업은 포함하지 않습니다.
