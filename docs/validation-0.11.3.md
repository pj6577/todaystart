# 0.11.3 — 원티드 조건 검색과 목록의 이전 지원 안내

검사일: 2026-11-02.

- 통합검색의 공통 직군·직무·지역·경력을 원티드 요청에 연결하고 조건 미지원 처리를 제거했습니다. 검색어와 직무를 함께 선택하면 두 서버 목록의 공고 ID를 대조하며 페이지 간 후보를 유지합니다.
- 원티드 실제 공개 HTTP 응답에서 검색어 API의 직무 조건 무시와 목록 API의 검색어 무시를 확인했습니다. 실제 앱 요청 코드를 Node에서 실행해 `React + 프론트엔드 + 서울 + 신입~3년` 첫 조회 3건과 다음 조회 추가 5건을 대조했습니다. 검색어 없는 같은 조건, 복수 직무·지역·2~5년 조건도 첫 두 페이지에서 각 12건을 읽었습니다.
- 연차와 직무 범위는 원티드의 분류·검색 의미를 따릅니다. `20`은 20년 이상, 경력무관 포함은 원티드 전체 옵션에 대응합니다. 상세 조건과 요청 경로는 [통합검색 기록](job-search-demo.md)에 있습니다.
- 제공받은 원티드 목록 DOM을 재구성한 테스트로 카드 이력 안내·무한 스크롤·속성 변경·목록 교체·중복 방지와 링크·북마크 분리를 확인했습니다. 이력 안내를 위해 추가 네트워크 조회나 지원 기록 저장을 하지 않습니다.
- 단위 테스트 49개 파일·610개 항목을 통과했습니다. 검색 화면의 메모리 상태 유지·새 검색 초기화·부분 실패 재시도·중지/재개·화면 종료 취소와 빈 대조의 자동 추가 조회 제한을 포함합니다. TypeScript 검사와 프로덕션 0.11.3 빌드를 확인했습니다.
- ZIP CRC·빌드 바이트 일치·버전·매니페스트 참조·기존 권한·라이선스·민감 패턴을 검사합니다. 결과와 SHA-256은 `release/todaystart-0.11.3-validation.json` 및 `.sha256`에 기록합니다.
- 사용자 요청에 따라 브라우저 실행·화면 확인·E2E 검사는 생략했습니다. 공개 HTTP 검사는 실제 Chrome 확장 환경의 연결 성공을 보장하지 않습니다. 이전 임시 headless 환경의 원티드 HTTP 403은 이번 변경으로 해결했다고 보고하지 않습니다.

`release/todaystart-0.11.3.zip`을 GitHub 릴리즈에 게시합니다. 같은 설치 폴더의 파일을 교체하고 확장 프로그램·관리 화면·열린 원티드 탭을 새로고침합니다. Chrome 웹스토어 게시 작업은 포함하지 않습니다.
