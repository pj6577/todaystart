# 0.11.4 — 공고 북마크와 검색 도구 높이 정리

검사일: 2026-11-02.

- 통합검색 카드의 지원 이력 배지 오른쪽에 북마크 저장·해제 버튼을 추가했습니다. 상단 북마크 보기에서는 검색 없이 저장한 공고를 읽고 플랫폼·지원 기업 제외 조건과 기존 이력 모달을 사용합니다.
- 북마크·플랫폼 필터 영역은 공통 필터 버튼과 같은 38px 높이이며, 상단 북마크 아이콘은 항상 채워 표시합니다. 카드의 이력 배지와 북마크는 30px로 맞추고 북마크 그림의 오른쪽 여백을 보정했습니다. 줄바꿈 시 위쪽 정렬을 유지합니다.
- 북마크는 공고별 로컬 저장소 키로 보관하며 사이트·공고 ID와 정규 공고 URL을 검증합니다. 원문 응답이나 임의의 추적 쿼리는 저장하지 않습니다. 전체 데이터 초기화에 맞춰 정리하며 오래된 화면의 재저장을 거부합니다. 기존 지원 기록 DB·JSON 백업 형식과 확장 권한은 유지합니다. 북마크는 현재 JSON 백업에 포함하지 않습니다.
- 단위 테스트 51개 파일·626개 항목, TypeScript 검사, 프로덕션 0.11.4 빌드를 확인합니다. 저장·해제·재진입 복원·불필요한 조회 방지·다른 탭 변경·손상 항목·저장 실패·초기화 세대 보호를 포함합니다.
- ZIP CRC·현재 빌드와 바이트 일치·버전·매니페스트 참조·기존 권한·content script 등록·라이선스·민감 패턴을 검사합니다. 결과와 SHA-256은 `release/todaystart-0.11.4-validation.json` 및 `.sha256`에 기록합니다.
- 사용자 요청에 따라 브라우저 실행·실제 화면·E2E 검사는 실행하지 않습니다. DOM 단위 테스트는 동작 검증이며 실제 화면의 픽셀 정렬 검사와 구분합니다. 이번 릴리스에서 실제 채용 사이트 연결 검사는 다시 실행하지 않습니다.

`release/todaystart-0.11.4.zip`을 GitHub 릴리즈에 게시합니다. 같은 설치 폴더에 파일을 교체한 뒤 확장 프로그램과 관리 화면을 새로고침합니다. 기존 릴리즈를 덮어쓰거나 Chrome 웹스토어에 게시하지 않습니다.
