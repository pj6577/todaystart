# 오늘시작 개인정보 보호정책 초안

개정일: 2026-10-21 / 대상 버전: 0.9.1

이 문서는 현재 구현의 처리 방식을 설명하는 배포 전 초안입니다. 정식 배포 전 운영자명, 연락처, 시행일, 정책 공개 URL을 확정해야 합니다. 현재 Web Store 심사·게시가 완료된 상태는 아닙니다. 개인정보 공개 항목은 [Chrome Web Store의 사용자 데이터 안내](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)에 맞춰 실제 배포 시 검토해야 합니다.

## 목적과 처리 항목

0.9.1은 리멤버 채용공고 목록(`https://career.rememberapp.co.kr/job/postings`)의 기업명·직무·공고 ID와 주소를 읽어 기존 지원 기록과 비교하고 카드 안에 이전 지원 이력을 표시합니다. 공고를 탐색했다는 이유로 새 지원 기록을 만들지 않으며 저장용 공고 URL에서 조회 세션·유입 경로 등 쿼리와 해시를 제거합니다. 지원 이력 수집은 기존 프로필 호스트의 `/applies`에 한정합니다. 리멤버 공고 페이지에도 기존 경고와 동일하게 기업명·지원 직무·지원일·지원 경로가 표시될 수 있습니다.

0.9.0은 리멤버 지원 목록(`https://profile.rememberapp.co.kr/applies`)에서 현재 표시된 기업명·직무·접수일·지원 상태와 명시된 열람 상태를 읽습니다. 지원 ID와 공고 주소가 제공되지 않는 카드에는 값을 만들지 않으며 기업명·직무·접수일의 복합 키를 사용합니다. 상단 집계 숫자나 추천 공고는 지원 기록으로 저장하지 않습니다. 기간 선택과 지원 취소 포함 여부는 수집 범위가 바뀌었는지 대조하기 위한 해시에만 반영합니다. 자세히 보기 버튼을 자동으로 열거나 별도 API를 요청하지 않습니다. 기존 플랫폼별 설정은 유지하고 새 리멤버 수집 설정을 추가하며 지원 현황 자동 가져오기의 기존 선택을 유지합니다. 리멤버 최종 지원 제출은 관찰하지 않습니다.

오늘시작은 사람인·잡코리아·원티드에서 지원 이력을 모으고 중복 지원 가능성을 표시하기 위해, 수집 설정이 켜진 플랫폼의 현재 열린 화면에 제공된 기업명, 공고명, 지원일, 지원 상태, 공고 URL, 지원/공고 ID, 제공되는 기업 식별자, 수집·확인·동기화 시각을 처리합니다. 사용자는 기업 홈페이지·이메일 등에서 지원한 기록과 경로 이름을 직접 입력할 수도 있습니다. 공고 경고를 표시할 때에는 현재 화면의 기업명과 공고 정보를 읽어 저장된 이력과 비교합니다.

플랫폼별 수집 상태, 화면 모드, 기능 설정, 사이트 선택자 설정, 마지막 수집 결과·조회 범위도 브라우저에 저장합니다. 사람인·잡코리아·원티드 자동 수집은 새 설치에서 기본으로 켜져 있습니다. 설정 화면에서 플랫폼별 자동 수집을 끄면 그 플랫폼의 추가 수집을 멈춥니다. 0.1.0에서 0.2.0으로 갱신할 때는 요청된 기본값으로 한 번 이전했습니다. 0.5.0은 기존 플랫폼 선택을 유지하고 새 원티드만 기본으로 켭니다. 기존 기록은 유지되며 관리 화면에서 삭제할 수 있습니다. 경고 표시는 설정의 목록/상세 경고로 각각 끌 수 있습니다.

아이디, 비밀번호, 로그인 세션, 인증 토큰, 쿠키 원문, 이력서 본문, 페이지 전체 HTML은 수집·저장하지 않습니다. 자동 수집 공고 URL은 등록된 플랫폼의 HTTPS URL만 허용합니다. 직접 지원 기록은 기업 홈페이지 등 외부 HTTPS 링크를 저장할 수 있으며 해당 주소를 수집하거나 추가 접근 권한을 요청하지 않습니다. 인증 정보가 있는 URL은 거절하고 임의 쿼리와 해시 정보는 제거합니다. 단, 개발자가 부적절하게 선택자 파일을 작성하면 의도하지 않은 텍스트가 필드에 포함될 수 있으므로 비식별화 샘플로 검증한 파일만 사용해야 합니다.

## 저장·전송

0.6.7은 원티드 최종 ‘제출하기’의 실제 클릭과 같은 탭·공고의 완료 경로 `/wd/{공고번호}/applied`를 연결합니다. 공개 공고 ID·기업명·직무·정규 공고 URL·관찰 시각을 기존 임시 흐름과 완료 기록에 보관합니다. 입력값·이메일·전화번호·이력서·첨부파일 ID·제출 전 지원 ID는 읽거나 저장하지 않습니다. 제출 요청·응답을 가로채거나 재전송하지 않고 기존 원티드 동의·자동 기록 설정을 따릅니다. 추가 권한이나 외부 전송은 없습니다.

0.6.5는 잡코리아 지원하기 버튼의 실제 클릭 시각을 임시 흐름에 보관하고, 해당 OnPass 문서에서 클릭 뒤 보이는 추가지원 버튼으로 바뀌는 전환을 완료 근거로 사용합니다. 검색 카드의 실제 공개 공고 ID와 열린 지원창의 giNo도 연결합니다. 클릭만으로는 지원 완료로 기록하지 않습니다. 버튼 HTML·onclick 코드·화면 전체 텍스트를 저장하거나 실행하지 않습니다. 클릭 전 추가지원 버튼의 요소 참조는 해당 문서 메모리에서만 비교하며 저장소로 전송하지 않습니다. 지원창과 완료 화면의 감시는 문서가 열려 있는 동안 유지하며 추가 권한이나 외부 전송은 없습니다.

0.6.1은 사람인 완료 문서에서 실제 URL의 숫자 공고·지원 ID와 보이는 완료 문구를 대조합니다. 완료 문서 전체 HTML이나 화면 텍스트는 저장·전송하지 않으며 두 ID·관찰 시각·완료 확인 방식만 기존 흐름에 보관합니다. 잡코리아는 공개 공고 ID와 지원창의 숫자 giNo를 별도 보관하고 같은 출처의 parent/opener 공고 정보 또는 실제 지원 링크로 연결합니다. 추가 접근 권한이나 외부 전송은 없습니다.

0.6.0은 최종 제출 관찰을 위해 최근 100개의 지원 흐름 상태·요청 ID·탭/프레임/문서 ID·관찰 시각과 선택적인 기업·공고 정보를 로컬에 보관합니다. 공고 정보 캐시는 24시간·100개로 제한합니다. 사람인 지원 iframe의 기존 최종 제출 응답에서 성공 코드와 숫자 지원·공고 ID만 사용합니다. 잡코리아는 특정 폼의 제출과 결과 문서 이동을 관찰합니다. 원티드 최종 제출은 관찰하지 않습니다. 제출 요청을 재전송하지 않고 요청 본문·이력서·첨부파일·응답의 content나 계정 정보는 저장하지 않습니다. 자동 기록/플랫폼 동의를 끄면 추가 관찰·저장을 중단합니다. 지원 현황 자동 가져오기는 별도 설정이며 기본 꺼짐입니다. 진행 안내 닫기 식별자도 브라우저에 저장합니다.

0.5.7은 플랫폼별 전체 수집 완료 시각과 사용자가 닫은 작업 안내의 식별자를 `chrome.storage.local`에 저장합니다. 다른 사이트를 수집하거나 브라우저를 다시 열어도 완료 체크와 안내 닫기를 유지하기 위한 값입니다. 외부 전송이나 추가 접근 권한은 없습니다.

0.5.6은 열람 여부를 별도 보관하며 원티드의 작성시간·사이트 진행 상태를 지원일·공통 상태와 구분합니다. 원티드 목록이 인식되고 수집이 켜져 있거나 사용자가 수집을 요청한 경우, 현재 페이지의 리소스 기록에서 확인된 동일 출처 `/api/v1/applications` 주소를 현재 로그인 상태로 조회할 수 있습니다. 쿠키 원문이나 인증 헤더를 읽거나 저장하지 않으며 주소를 추측하기 위해 다른 저장소를 읽지 않습니다. 응답은 지원/공고/기업 ID, 기업명, 포지션, 작성시간, 열람 여부, 상태의 허용 필드만 즉시 추립니다. 응답의 이력서·프로필·계정 필드는 캐시나 지원 기록에 복사하지 않습니다. API가 실패해도 DOM 기록을 유지합니다. 열람 정보 미확인은 미열람으로 간주하지 않습니다.

사용자가 ‘지원 기록 가져오기’ 또는 ‘조회 기간 전체 가져오기’를 누르면 현재 조회 조건을 유지하며 같은 지원 현황 탭의 첫 페이지·다음 페이지를 순차적으로 엽니다. 수집 작업의 탭 ID, 조회 조건을 비교하기 위한 해시, 페이지별 목록 해시, 진행 건수와 상태는 `chrome.storage.session`에 임시 보관하며 브라우저를 닫으면 사라집니다. 임의의 URL 쿼리 원문은 작업 상태에 보관하지 않습니다. 작업은 팝업 또는 관리 화면에서 중지할 수 있습니다. 로고는 로컬 번들에 포함해 외부 이미지 요청을 하지 않습니다.

지원 현황의 초기 목록은 최대 45초 동안 준비를 기다립니다. 사이트 화면의 상태 안내에는 수집 중·완료·중지 상태와 처리 페이지·건수를 표시합니다. 전체 작업 정보는 해당 탭에만 제공하며 화면에서도 중지할 수 있습니다. 상태 안내의 ‘대시보드 열기’는 확장 프로그램 관리 화면을 엽니다. 이 안내는 Shadow DOM에 표시되며 회사·직무·계정 정보를 추가로 포함하지 않습니다.

사용자가 팝업에서 ‘화면 진단 파일 저장’을 누르면 지원 현황의 텍스트·입력값·스크립트·임의 속성·URL 쿼리·숫자 식별자를 제거한 HTML 구조를 로컬 JSON으로 내보냅니다. 지원 목록의 인식 문제를 확인하기 위한 기능이며 확장 프로그램이 진단 파일을 외부로 전송하지 않습니다.

진단에는 표별 행·셀·공고 링크의 개수, 관찰 영역 포함 여부, 인식·제외 건수, 페이지 컨트롤의 태그와 링크 유형을 함께 기록합니다. 이 메타데이터에는 기업명·직무·실제 지원 날짜·공고 ID·JavaScript 코드·입력값을 포함하지 않습니다.

지원 이력은 확장 프로그램 오리진의 IndexedDB에, 설정과 진단은 `chrome.storage.local`에 저장합니다. 별도 서버, 계정, 클라우드 DB, 외부 AI API, 광고·분석 SDK를 사용하지 않습니다. 확장 프로그램은 수집 이력을 외부 서버로 전송하지 않습니다. 자동 Chrome Sync를 사용하지 않습니다.

중복 경고를 위해 일부 기존 지원 정보를 현재 채용 사이트 DOM에 삽입합니다. 따라서 경고 화면에 표시한 정보는 해당 페이지의 실행 코드가 읽을 수 있는 영역입니다. 사이트 자체의 정보 처리 정책은 각 사이트 정책을 따릅니다. 브라우저 로컬 데이터는 운영체제·브라우저 프로필 접근 권한의 보호를 받으며 별도의 애플리케이션 암호화는 제공하지 않습니다.

## 보관·수정·삭제·백업

사용자가 기록을 삭제하거나 확장 프로그램/브라우저 프로필을 제거할 때까지 로컬에 보관합니다. 목록에서 사라졌다는 이유로 기록을 삭제하지 않습니다. 지원 기록 관리 화면에서 개별 기록을 검색·수정·삭제하고 JSON으로 전체를 백업·복원하거나 CSV로 현재 표시 범위를 내보낼 수 있습니다.

내보낸 파일은 사용자가 선택한 파일 시스템에 저장되며 확장 프로그램을 제거해도 남습니다. 공유·보관·삭제 책임은 파일을 관리하는 사용자에게 있습니다. 백업에는 지원 이력이 들어 있으므로 공개 저장소나 공유 폴더에 두지 않는 것을 권장합니다.

## 접근 권한

`storage`는 로컬 설정과 변경 통지, `activeTab`은 팝업에서 현재 탭 확인에 사용합니다. 사람인·잡코리아·원티드의 데스크톱 `www` 호스트 접근 권한은 현재 열린 화면의 지원 내역·공고를 읽고 경고를 표시하는 데 사용합니다. 0.9.0은 리멤버 지원 목록을 읽기 위한 `https://profile.rememberapp.co.kr/*` 호스트 접근 권한을 추가합니다. 이 호스트에서는 `/applies` 경로만 기본 수집 대상으로 판별합니다. 0.9.1은 리멤버 공고 목록의 이전 지원 이력 안내를 위한 `https://career.rememberapp.co.kr/*` 권한을 추가합니다. 그 외 사이트, 쿠키 API, 모든 방문 기록 접근 권한을 요청하지 않습니다.

## 문의 및 개정

운영자 및 문의 연락처: **정식 배포 전에 확정 필요**.

처리 항목이나 외부 전송 여부가 바뀌면 정책과 권한·설정 화면을 함께 갱신해야 합니다.
