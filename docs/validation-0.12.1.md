# 0.12.1 — 원티드 지원 상태·중복 기록 수정

검사일: 2026-11-04.

- 접수 상태의 DOM 수집과 API 보강에서 내부 상태·표시 문구를 함께 검사합니다. 접수만으로 열람했다고 판단하지 않으며 작성일을 지원일로 저장하지 않습니다.
- 실제 완료 추적 → 지원 현황 DOM → API 보강 → 반복 수집·늦은 문맥 수신을 한 지원으로 연결하는 통합 테스트를 실행합니다.
- 기존 중복의 재수집 복구, 양쪽 메모·일정 보존, 실제 지원일·제출 시각 보존과 백업 반복 복원을 검사합니다. 다른 직무·공고·지원 ID, 식별자 충돌과 모호한 후보를 자동 병합하지 않습니다.
- 전체 단위 테스트 769개, 타입 검사와 프로덕션 0.12.1 빌드를 실행합니다. 사용자 요청에 따라 브라우저 실행·화면 캡처·E2E 검사는 하지 않습니다.
- ZIP CRC·빌드 바이트 일치·버전·매니페스트 자원·라이선스·SHA-256을 검사합니다. 권한과 content script 등록은 0.12.0과 같습니다. 결과와 해시는 `release/todaystart-0.12.1-validation.json`, `.sha256`에 기록합니다.

0.12.0 릴리즈를 유지하고 0.12.1 설치 ZIP을 새 GitHub 릴리즈로 제공합니다. 같은 설치 폴더에 파일을 교체한 뒤 확장 프로그램·대시보드·원티드 탭을 새로고침하고 지원 내역을 업데이트합니다. Chrome 웹스토어에는 게시하지 않습니다.
