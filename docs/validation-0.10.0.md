# 0.10.0 — 준비 보드와 지원 기록 직접 추가

## 변경

- 캘린더·준비 보드·목록 탭과 종류·날짜 필터를 제공한다. 준비 보드는 전체 예정 일정을 날짜순으로 보여주며, 지난 미완료 일정과 다른 연도의 일정도 표시한다.
- 준비 상태와 실제 일정 완료를 구분한다. 카드 접기·펼치기, 드래그 이동, 체크리스트와 저장 실패 후 재시도를 지원한다.
- 일정 종류를 추가·수정·정렬·삭제하고 삭제한 종류의 일정을 재배치한다. 로컬 DB v4에 설정을 보관하고 백업·복원에도 포함한다.
- 확인 필요 항목의 직접 추가에서 확인된 기업명·직무·지원 경로·공고 주소와 수정 가능한 날짜를 채운다. 명시적으로 저장한 뒤 원래 지원 시도와 연결한다. 잡코리아 내부 지원창 ID를 공개 공고 ID로 사용하지 않는다.

[PR #3](https://github.com/pj6577/todaystart/pull/3)을 병합했고 이슈 #1·#2는 종료했다. 새 접근 권한이나 의존성은 추가하지 않았다.

## 검사

0.10.0에서 타입 검사, 단위 검사 38개 파일·420개, 프로덕션 빌드를 실행해 통과했다. 새 빌드의 브라우저 검사 13개도 통과했다.

- 대시보드 캘린더의 필터·월 이동·키보드와 4·5·6주 레이아웃
- 일정 종류 관리·백업 복원·현재 시각 기본값
- 준비 보드의 전체 일정·기간 필터·드래그·실제 일정 완료와 저장 실패 후 재시도
- 직접 추가 폼의 미리 채우기·수정·저장·취소·일반 폼 초기화
- 잡코리아 공개 공고 ID와 내부 지원창 ID 구분
- MV3 확장 프로그램 로드·최소 권한·관리 화면·팝업

설치 ZIP은 2,732,100바이트, 파일 45개다. 압축 무결성, manifest 버전과 참조 파일, 빌드와의 전체 바이트 일치, MAIN-world 관찰자 등록과 라이선스 포함을 확인했다. 0.9.3 ZIP과 접근 권한이 같다. 소스·테스트·과거 제작 자료를 제외하고 GitHub 토큰·디스코드 웹훅·개인 키·구글 API 키 패턴이 없는지 검사했다.

SHA-256: `5299c83907c0be79f5ab0975c5493e073cdfaabb9a44d4adccce8d8e89cffc05`

브라우저 검사는 임시 Chromium 프로필과 합성 문서로 수행했다. 실제 계정의 로그인·입사지원이나 Chrome Web Store 심사를 검증한 것은 아니다.

- 로컬 설치 ZIP: `release/todaystart-0.10.0.zip` (Git에는 포함하지 않음)
- 검증 메타데이터: `release/todaystart-0.10.0-validation.json`
- 설치 방법: `release/설치안내.txt`

기존 ZIP 설치를 업데이트할 때는 동일한 설치 폴더의 파일을 교체한 뒤 확장 프로그램과 관리 화면을 새로고침한다. 다른 폴더로 옮기는 경우 기존 데이터를 JSON으로 백업하고 필요하면 복원한다.
