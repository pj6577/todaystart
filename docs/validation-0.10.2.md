# 0.10.2 — 지원 완료 추적과 중복 이력 안내

관련 이슈: [#4](https://github.com/pj6577/todaystart/issues/4), [#5](https://github.com/pj6577/todaystart/issues/5), [#6](https://github.com/pj6577/todaystart/issues/6).

## 변경과 재현

- 잡코리아에서 닫힌 이전 제출창과 현재 제출이 함께 남아 있거나, 이전 시도와 새 결과 문서가 같은 후보에 들어오면 완료 표시를 연결하지 못했다. 브라우저의 문서·프레임 연결을 우선하고, 이전 창이 현재 제출 전에 닫힌 경우를 구분한다. 동시에 제출 중인 여러 창은 임의로 확정하지 않는다.
- 공고 번호가 있는 OnPassResult의 명시적 완료 문구와 의미가 같은 추가지원 컨트롤을 인식한다. 숨겨진 문구·안내 문장·다른 공고 번호·제출 전 완료 표시는 거절한다.
- 연결 실패 시 원인 코드와 창 종료 시각·결과 문서 ID를 로컬 지원 시도에 보관한다. 원문 URL 쿼리·이력서·폼 입력 내용은 진단에 넣지 않는다.
- 같은 사이트·공고·한국 지원 날짜의 안내를 묶는다. 완료 여부 확인의 빈 날짜는 오늘로 제안하되 기존 날짜와 취소 동작을 유지한다.
- 동일 상세 공고의 복수 헤더, 삽입기 재실행, 복제 안내에서 중복 삽입을 재현했다. 상세 공고는 보이는 헤더 하나를 선택하고 기존 안내를 재사용한다. 새 헤더로 소유권을 넘길 때 안내가 삭제되지 않도록 하며 접기 상태를 보존한다.
- 이전 main의 구버전 직접 추가 오류 안내, 지원 현황 대조, 사람인 지원 레이어 표시 중 안내 변경 보류도 이번 설치본에 포함한다.

## 검사

- `npm run typecheck`: 통과.
- `npm test -- --reporter=dot`: 43개 파일, 493개 테스트 통과.
- 프로덕션 빌드 후 관련 Playwright 35개 통과.
- 제출 요청과 결과 연결, 반복 창, 새 완료 문구, 다른 공고·숨김·제출 전 표시 배제, 지원 현황 대조, 안내 묶음·폼·날짜 기본값, 중복 헤더·안내 복제·헤더 교체, 사람인 완료창, MV3 로드·최소 권한·팝업을 확인한다.

실제 로그인 계정이나 입사지원 요청은 사용하지 않는다. 공개 경로와 비식별·합성 화면으로 검증했으며, 모든 실제 사이트 변형이나 제보 당시 개별 지원의 접수 여부를 확정한 것은 아니다. #4·#5의 실사용 최종 확인은 별도로 남긴다.
