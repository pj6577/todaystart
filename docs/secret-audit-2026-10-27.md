# 키·구글 계정 정보 점검

2026-10-27에 현재 작업 폴더를 로컬에서 검사했다. 실제 값은 이 문서와 검사 출력에 기록하지 않았다. 발견한 키의 유효성을 확인하는 외부 요청도 보내지 않았다.

## 범위

- `src`, `scripts`, 설정, 테스트 자료, 문서, `.tmp`, `.plasmo`, 개발·프로덕션 빌드, `release`를 검사했다.
- 텍스트 파일 및 압축 내 텍스트 항목 5,432개, 약 169MB를 검사했다. ZIP 54개의 내부 항목 1,464개도 확인했다.
- 일반 프로젝트 자료 및 배포 ZIP 안의 서로 다른 이미지 247개를 Windows 로컬 OCR로 검사했다. 이메일·Gmail·구글 계정 문구·키 형태 후보는 없었으며 이미지 처리 오류도 없었다.
- 설치된 `node_modules` 전체는 검사 범위에서 제외했다. 앱에 번들된 의존성 코드는 빌드와 배포 ZIP 검사에 포함했다.
- 프로젝트 루트에 `.git`이 없으므로 과거 Git 커밋 이력은 검사하지 않았다.

## 결과

### 오늘시작 소스와 프로덕션 배포물

검사 패턴 기준으로 사용자 API 키, OAuth 클라이언트 비밀, 구글 액세스/리프레시 토큰, 서비스 계정 개인 키, 사용자 Gmail 주소는 발견되지 않았다. 개인정보가 담긴 Chrome `Cookies`, `Login Data`, `Local State` 파일이나 실제 자격 증명 JSON 파일도 발견되지 않았다.

소스 및 프로덕션 manifest에 `oauth2` 설정, `identity`/`identity.email` 권한, `key` 항목이 없다.

### 앱 외 임시 자료와 개발 빌드

| 위치 | 발견 사항 | 판단 |
| --- | --- | --- |
| `.tmp/gstack-trial/source/lib/diagram-render/dist/diagram-render.html` 및 그 내부 복사본 | 구글 API 키 형태의 동일한 값 1종, 총 2회 | Excalidraw 번들에 들어 있는 Firebase 클라이언트 설정. 오늘시작 소스·프로덕션 ZIP에는 포함되지 않는다. 키의 현재 유효성이나 소유권은 검증하지 않았다. |
| `build/chrome-mv3-dev/static/background/index.js` | Gmail 주소 1개 | Dexie 라이브러리 저작권 주석에 있는 개발자 연락처. 사용자 구글 계정 정보가 아니다. |
| `.tmp/gstack-trial/source` 아래 테스트·문서·정규식 파일 | 토큰·개인 키 헤더·쿠키 형태 탐지 후보 | 외부 도구의 테스트 및 예시·탐지 규칙에 해당한다. 오늘시작 코드와 배포물에서는 같은 후보가 발견되지 않았다. |

`.tmp/gstack-trial`은 스킬 설치 폴더와 별개로 프로젝트 안에 남아 있는 임시 소스 복사본이다. `.tmp/`, `build/`, `node_modules/`는 현재 `.gitignore`의 제외 대상이다. 이 검사에서 기존 소스나 임시 폴더를 삭제하지 않았다.

## 해석 범위

이는 알려진 패턴 검색과 이미지 문자 인식 결과다. 이미지 OCR 오인식이나 암호화·임의 형식의 숨겨진 비밀까지 없다고 보증하지는 않는다. 공개할 파일 목록을 확정한 뒤 그 목록과 향후 생성되는 배포물에 대해 같은 검사를 다시 수행하는 것이 적절하다.
