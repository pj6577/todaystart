# 0.11.1 — 검색 조건 기억과 직군 목록 스크롤 수정

검사일: 2026-11-02. 실제 계정과 입사지원 요청은 사용하지 않았습니다.

## 변경과 확인 범위

- ‘조건 설정’을 ‘검색 사이트’로 바꾸고 경력 바로 옆에 배치했습니다. 실험 기능 배지와 직군·직무의 복수 선택 힌트·직군 선택 안내 문구를 제거했습니다.
- 마지막으로 적용한 검색어·복수 직군/직무·지역·경력 범위·검색 사이트·지원 기업 제외 설정 한 건을 로컬에 보관합니다. 화면 재진입·새로고침·새 탭에서 복원하고 자동 조회하지 않는지 확인했습니다.
- 새 적용 시 한 건 교체, 전체 초기화·사이트만 선택, 취소한 임시 선택과 미제출 입력 제외, 손상된 값의 기본값 복구, 저장소 오류 중 검색 동작을 확인했습니다.
- 직군 하단을 선택하면 숨겨진 radio의 위치 때문에 모달 자체가 스크롤되는 현상을 기존 빌드에서 재현했습니다. 선택 컨트롤의 기준 위치를 각 행으로 고친 뒤 모바일·데스크톱과 라이트·다크에서 하단 연속 클릭·방향키 이동·적용 버튼 위치를 확인했습니다.
- 개인정보 정책과 설명 문서에 마지막 검색 설정의 로컬 보관 범위를 반영했습니다. 검색 결과·응답·페이지 진행·검색 이력 목록은 저장하지 않습니다.

## 통과한 검사

- TypeScript 검사, 전체 단위 테스트 582개.
- 프로덕션 0.11.1 빌드와 통합검색 브라우저 테스트 22개.
- ZIP CRC·빌드 파일 일치·버전·매니페스트 참조·라이선스·주요 민감 패턴 검사.
- 이전 0.11.0과 권한 및 사이트 관찰 content script·백그라운드 번들 바이트 비교.

통합검색 브라우저 검사는 합성 검색 응답을 사용합니다. 실제 검색 사이트의 접근 제한이나 구조 변경에 따른 차이까지 보장하지 않습니다. 기존 전체 수집 브라우저 검사의 시간·상태 판정 실패는 이번 변경 범위가 아니며 전체 브라우저 스위트 통과를 주장하지 않습니다. 원티드 조건 검색은 계속 연결 전입니다.

## 설치 파일

`release/todaystart-0.11.1.zip`과 동일한 ZIP을 GitHub 릴리즈에 게시합니다. `.sha256`과 `-validation.json`에 해시·검증 범위를 기록하며 Git에는 ZIP 대신 검증 자료를 보관합니다. 기존 설치 폴더의 파일을 교체한 뒤 확장 프로그램과 관리 화면을 새로고침합니다. Chrome 웹스토어 게시 작업은 포함하지 않습니다.
