# 0.9.3 — 사람인 목록 인식과 반복 작업 성능 개선

## 변경

- 사람인 `/zf_user/jobs/list` 계열의 `.list_body` 일반 공고와 추천 슬라이드를 각각 인식한다. 링크 대신 `span`으로 표시된 회사명도 읽는다. 그룹명·방문 표시를 지원 이력으로 판단하지 않고 실제 저장된 지원 기록을 비교한다.
- 기업명·사이트별 기업 ID 색인과 제한된 결과 캐시를 사용한다. 메모의 지원 기록 조회에서 중첩 반복을 제거한다.
- 메모·일정 변경 알림을 지원 기록 변경과 분리한다. 플래너 전용 조회로 채용 탭의 전체 지원 기록 재조회를 줄인다.
- 지원 기록을 페이지당 100건씩 표시한다. 검색·필터·정렬 변경 시 첫 페이지로 돌아가고, CSV는 검색 결과 전체를 내보낸다.
- 검색·정렬·메모 개수를 재사용하고, 변하지 않은 공고 안내의 재렌더를 생략한다. DOM 파싱·카드 교체 감지·제거된 안내 복구는 유지한다.

기존 기록과 메모·일정 저장 형식을 유지하며 새 권한이나 의존성은 추가하지 않는다.

## 검사
