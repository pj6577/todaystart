# 0.11.2 — 지원 기업 제외 옵션 배치

검사일: 2026-11-02.

- 데스크톱의 ‘지원 기업 제외하기’를 검색 사이트와 같은 줄 오른쪽 끝으로 옮겼습니다. 모바일은 다음 줄 왼쪽에 표시합니다.
- 선택 조건 칩은 도구 모음 아래에 유지합니다. 변경은 JSX 배치와 CSS에 한정하며 검색·저장·기업 비교 로직은 변경하지 않았습니다.
- TypeScript 검사와 프로덕션 0.11.2 빌드를 통과했습니다.
- ZIP CRC·빌드 파일 일치·버전·매니페스트 참조·라이선스·주요 민감 패턴을 검사하고, 이전 0.11.1과 권한 및 content script·백그라운드 번들의 바이트를 비교했습니다.
- 사용자 요청에 따라 브라우저 실행·화면 확인·브라우저 테스트는 생략했습니다. 이전 버전의 테스트 결과를 이번 버전에서 재실행한 결과로 보고하지 않습니다.

`release/todaystart-0.11.2.zip`과 동일한 ZIP을 GitHub 릴리즈에 게시합니다. 기존 설치 폴더의 파일을 교체하고 확장 프로그램과 관리 화면을 새로고침합니다. 검색 사이트 접근 제한과 원티드 조건 검색 연결 전 상태 등 기존 제한은 유지합니다. Chrome 웹스토어에는 별도로 게시하지 않습니다.
