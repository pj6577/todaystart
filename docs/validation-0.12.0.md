# 0.12.0 — 리멤버 검색과 공고 탐색·지원 이력 보완

검사일: 2026-11-04.

- 리멤버 통합검색에 검색어·직군·직무·지역·경력을 연결했습니다. 경력무관과 연차의 OR 선택은 최대 세 네이티브 요청을 합치며 모든 분기에 같은 검색 조건을 전달합니다. 공고 ID·응답 형식·페이지를 검증하고 필요한 텍스트·정규 공고 링크만 사용합니다.
- `https://career-api.rememberapp.co.kr/*` 호스트 권한 한 곳을 추가합니다. 쿠키·인증정보·기기 ID는 보내지 않습니다. 일반 권한과 기존 content script 등록, 기존 DB·백업 형식은 유지합니다.
- 플랫폼 탭을 마우스·터치로 끌거나 Alt+좌우 방향키로 옮기면 결과의 플랫폼 순서도 바뀌고 브라우저에 저장됩니다. 전체와 북마크 버튼은 고정하며 Esc·포인터 취소·창 비활성화·화면 종료와 드래그 후 클릭 억제를 검사했습니다.
- 추가 조회는 대상 응답이 끝나면 선택한 플랫폼 순서로 새 묶음을 맨 아래에 붙입니다. 리멤버가 먼저 응답해도 다른 사이트의 새 공고가 위쪽에 끼어들지 않습니다. 중지·같은 페이지 재개·일부 실패·재시도와 원티드 대조 캐시 복원을 검사했습니다.
- 표시용 한영 병기 기업명 키를 통합검색과 실제 공고 안내에서 공유합니다. 제공된 원티드 `/wd/325032` 카드와 사람인의 `(주)아인잡` 완료 이력을 재구성해 이전 경로·직무·날짜 표시를 검사했습니다. 지점·계열사·조직·다른 이름과 같은 사이트의 기업 ID 충돌은 구분합니다. 저장 이름·기록 식별자·자동 병합 기준은 유지합니다.
- 잡코리아 상세의 보이는 지원완료 버튼과 같은 공고의 기업명·직무를 확인해 기존 기업 기록이 없는 경우 보완합니다. 설정·현재 탭·공고 ID·초기화 세대를 검사하며, 실제 지원일·지원 ID를 추정하지 않습니다. 나중의 지원 현황에서 단일하게 연결되는 실제 정보만 보강하고 기존 메모·일정 연결을 유지합니다.
- 단위 테스트 735개, TypeScript 검사, 프로덕션 0.12.0 빌드를 실행합니다. ZIP CRC·빌드 바이트 일치·버전·매니페스트 자원·허용한 권한 변경·content script 등록·라이선스를 검사하고 결과와 SHA-256을 `release/todaystart-0.12.0-validation.json` 및 `.sha256`에 기록합니다.
- 2026-11-03 공개 HTTP 조사에서 네 사이트의 키워드 및 프론트엔드·서울·신입~3년 조건을 1~3페이지씩 실제 클라이언트·파서로 조회해 새 공고 ID와 다음 페이지를 확인했습니다. 리멤버의 경력 OR와 빈 결과도 확인했습니다. 실제 사용자 검색 조건 전부나 확장 브라우저 환경의 연결성을 보장하는 검사는 아닙니다.
- 사용자 요청에 따라 브라우저 실행·화면 캡처·E2E 검사는 실행하지 않습니다. DOM 단위 검사는 실제 화면의 픽셀·터치 동작 확인과 구분합니다. 잡코리아 인증된 지원완료 상태는 사용자 제공 DOM 재구성으로 검증했습니다. 실제 계정 제출은 실행하지 않았습니다.

`release/todaystart-0.12.0.zip`을 새 GitHub 릴리즈에 게시합니다. 같은 설치 폴더에 교체한 뒤 확장 프로그램·관리 화면·열려 있는 채용 사이트 탭을 새로고침합니다. 기존 릴리즈는 덮어쓰지 않고 Chrome 웹스토어에는 게시하지 않습니다. 검색 북마크와 플랫폼 표시 순서는 기존 지원 기록 JSON 백업에 포함되지 않습니다.
