이전 지원 확인

다른 사이트에서 만나도,
이전 지원을 알아봐요.

공고를 살펴볼 때 저장된 기업 이력을 함께 보여줘요. 지원했던 경로와 날짜, 직무를 확인하고 다음 지원을 결정하세요.

  • 같은 사이트와 다른 사이트의 기록 비교
  • 이름이 비슷한 기업은 확인 필요 안내

저장된 기록을 기준으로 안내하며, 실제 지원 여부와 동일 기업 여부는 직접 확인해 주세요.

지원 기록 관리

여러 곳의 지원 기록을,
한눈에 살펴봐요.

채용 사이트에서 가져온 지원과 직접 추가한 기록을 한곳에 모아요. 기업과 직무로 검색하고, 경로와 상태별로 정리할 수 있어요.

  • 지원 기록 검색·필터·상태 수정
  • CSV 내보내기와 JSON 백업·복원

사이트의 로그인 상태와 화면 구조에 따라 가져오기 범위가 달라질 수 있어요.

메모와 일정

기업 조사부터 면접 복기까지,
기록 옆에 남겨요.

기업을 언급해 메모를 연결하고 체크리스트로 준비해요. 면접·과제·마감 일정도 지원 기록과 함께 관리할 수 있어요.

  • 자동 저장되는 메모와 할 일 목록
  • 지원 기록과 연결하는 취업 캘린더

브라우저 프로필이나 확장 프로그램을 삭제하기 전에는 JSON으로 백업해 주세요.

로그인이나 별도 계정이 필요한가요?+

오늘시작 전용 계정은 필요하지 않아요. 지원 현황을 가져올 채용 사이트에는 로그인되어 있어야 해요. 확장 프로그램이 비밀번호나 쿠키 원문을 읽어 저장하지는 않아요.

지원 기록이 자동으로 다른 기기에도 보이나요?+

기록은 설치한 브라우저 프로필에 보관되며 자동 동기화하지 않아요. 다른 환경으로 옮길 때는 JSON 백업·복원 기능을 사용하세요. 백업 파일에는 지원 이력이 들어 있으니 직접 안전하게 보관해 주세요.

모든 이전 지원을 찾아주나요?+

가져오거나 직접 추가해 저장한 기록을 기준으로 확인해요. 회사명 표기가 다르거나 이름만 비슷할 수 있으므로 실제 지원 여부와 동일 기업 여부는 직접 확인해 주세요. 완료 근거가 부족한 지원 시도는 확인 대기로 표시해요.

휴대폰에서도 사용할 수 있나요?+

오늘시작은 데스크톱 Chrome 확장 프로그램이에요. 이 소개 페이지는 휴대폰에서도 볼 수 있지만, 설치와 채용 사이트 연동은 데스크톱 Chrome에서 진행해 주세요.

공개된 코드를 수정하거나 재배포해도 되나요?+

개인 사용과 비공개 수정은 허용해요. 소스·설치 파일 재배포, 상업적 이용과 타인 대상 서비스 운영에는 사전 서면 허가가 필요해요. 개인정보 외부 수집 기능을 추가할 권한은 부여하지 않아요. 전체 조건은 소스 라이선스를 확인해 주세요.
