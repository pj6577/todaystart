# 오늘시작 랜딩페이지

GitHub Pages에 게시하는 정적 소개 페이지입니다. 확장 프로그램과 별도 빌드하며 런타임 의존성·외부 서체·방문자 분석·폼을 사용하지 않습니다. 브라우저 저장소에는 화면 모드 선택값 하나만 보관하며 확장 프로그램 데이터에 접근하지 않습니다.

## 디자인 기준

- 기존 Clear Product 원칙: 중립색 배경, 대비가 충분한 본문, 문장 단위 제목과 기능을 바로 이해할 수 있는 시각적 설명.
- [샤플 HR 소개 페이지](https://www.shoplworks.com/use-case/hr)의 시각적 표현을 참고해 라이트 모드의 옅은 푸른색 면, 큰 둥근 모서리, 낮은 그림자와 중간 굵기의 제목을 적용합니다. 참고 사이트의 이미지·로고·카피를 복제하지 않습니다.
- 다크 모드는 `src/style.css`의 실제 대시보드 색상과 맞춥니다. 페이지 `#09090b`, 카드 `#18181b`, 선택 배경 `#27272a`, 본문 `#fafafa`, 보조 본문 `#d4d4d8`, 설명 `#a1a1aa`, 주요 버튼 `#1d4ed8`을 기준으로 합니다. 푸른 페이지 배경을 추가하지 않습니다.
- 파란색은 주요 설치 버튼과 실제 링크에 제한합니다. 원본 아이콘의 따뜻한 색상은 유지합니다.
- 글래스모피즘은 반투명 내비게이션·미리보기 프레임·기능 패널에 적용합니다. 흰 경계와 중립색 그림자로 깊이를 만들고 형광 테두리는 사용하지 않습니다.
- 본문은 짙은 색과 충분히 불투명한 바탕을 사용합니다. 블러 미지원·투명 효과 축소·동작 축소 환경도 지원합니다.
- 첫 방문은 다크 모드이며 상단에서 시스템·다크·화이트를 선택할 수 있습니다. 시스템 모드는 운영체제 변경을 따르고, 선택값은 새로고침·페이지 이동 시 유지합니다. 색상 변수는 라이트·다크 표면과 대비를 함께 정의합니다.
- 상단 화면 모드 선택은 현재 모드의 아이콘만 표시하며, 기본 선택 메뉴와 키보드 조작을 유지합니다. 주요 메뉴는 좌우 영역과 관계없이 화면 중앙에 배치합니다.
- 설치 버튼의 컬러 Chrome 아이콘은 [Google 공식 Chrome 페이지](https://www.google.com/chrome/)의 [원본 SVG](https://www.google.com/chrome/static/images/chrome-logo-m100.svg)를 그대로 보관했습니다. 플랫폼 아이콘은 기존 `assets/platforms` 원본이며, 제품 식별 용도로 사용합니다. 각 권리자의 조건은 별도로 적용됩니다.
- 상단 제품 화면은 현재 확장 프로그램을 임시 프로필에서 라이트·다크로 각각 촬영한 원본입니다. 페이지의 모드와 같은 이미지가 표시되며 색상 반전 필터는 사용하지 않습니다. 화면 위에 버전·데이터 출처 캡션을 붙이지 않습니다. 촬영 정보는 `assets/screens/capture-info.json`에 별도로 기록합니다.
- 기능 소개는 HTML·CSS·SVG로 만든 설명용 UI 일러스트입니다. 이전 지원 알림, 여러 경로의 기록 모으기, 기업 메모와 면접 일정을 세 개의 카드로 보여줍니다. 작은 전체 화면이나 탭 조작 없이 내용을 볼 수 있고 화면 모드·모바일 너비에 맞춰 표시됩니다.
- 사이트 소개는 현재 지원하는 4개와 Future 14개를 분리합니다. Future는 확장 검토 대상이며 현재 자동 연동이나 제공 일정을 의미하지 않습니다. 다른 경로의 지원 기록은 직접 추가할 수 있습니다.

## 제품 화면 다시 촬영하기

```sh
npm run build
node scripts/capture-landing.cjs
```

합성 지원 기록·메모·일정을 임시 프로필에 넣고 실제 앱과 이전 지원 안내를 촬영합니다. 채용 사이트 요청은 로컬 문서로 대체하고 다른 외부 요청은 차단합니다. 실제 로그인 프로필이나 사용자 데이터를 사용하지 않습니다. 메모·캘린더·안내 캡처는 제작 원본으로 보관하며 현재 배포에는 상단에서 참조하는 대시보드 두 장만 포함합니다.

## 로컬 확인

```sh
node scripts/build-landing.cjs
python -m http.server 4173 --directory build/landing
```

`http://localhost:4173`을 엽니다. 출력은 `build/landing`에만 생성하며 Git에서 제외합니다. 빌드 스크립트는 명시한 HTML·CSS·JavaScript·서체·대표 이미지·고지만 복사합니다.

## 배포

`.github/workflows/pages.yml`에서 `main`의 관련 파일 변경 또는 수동 실행 시 빌드·배포합니다. PR에서는 빌드만 확인하며 게시 권한을 주지 않습니다. 배포 대상은 `github-pages` 환경과 `build/landing` 아티팩트입니다. 별도 배포 키나 외부 서비스 토큰은 필요하지 않습니다.

개인정보 처리 설명은 `privacy.html`, 이용 조건은 루트 `LICENSE`, 제3자 자산 조건은 `THIRD_PARTY_NOTICES.md`와 서체 고지를 따릅니다. GitHub Pages 자체의 보안 목적 IP 로그는 개인정보 안내에 별도로 표시합니다.
