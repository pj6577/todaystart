오늘시작 0.10.1 — Chrome/Whale 로컬 테스트

1. todaystart-0.10.1.zip을 원하는 위치에 압축 해제합니다.
2. Chrome 주소창에서 chrome://extensions 를 엽니다.
3. 우측 상단 개발자 모드를 켭니다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
5. 압축 해제한 폴더 안에서 manifest.json이 바로 들어 있는 폴더를 선택합니다.
6. Chrome 확장 프로그램 메뉴에서 '오늘시작'을 고정합니다.
7. 팝업의 '대시보드 열기'에서 화면과 설정을 확인합니다.

ZIP 파일 자체를 Chrome 화면에 끌어다 놓는 방식이 아니라,
압축을 푼 폴더를 위 방법으로 로드해야 합니다.

이미 프로젝트 폴더로 설치했다면 chrome://extensions에서 오늘시작의 새로고침 버튼을 누릅니다.
프로젝트에서 직접 빌드했다면 로드할 폴더: build/chrome-mv3-prod
프로젝트 루트 폴더에는 manifest.json이 없으므로 루트를 선택하면 안 됩니다.

기존 ZIP 설치를 업데이트할 때는 같은 설치 폴더의 파일을 교체하고 확장 프로그램을 새로고침하세요.
다른 폴더에 새로 설치하면 저장소가 분리될 수 있으므로, 먼저 JSON 백업 후 필요하면 복원하세요.
